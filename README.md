# b2b-banking-analytics

Небольшой pet-проект для анализа клиентов и продуктов B2B-банкинга.

В проекте можно посмотреть:

- количество клиентов;
- общую и среднюю выручку;
- уровень оттока;
- выручку по отраслям;
- использование банковских продуктов;
- несколько простых сегментов клиентов, на которые стоит обратить внимание.

Данные синтетические и генерируются в `generate_data.py`.

## Стек

- Python
- Pandas
- NumPy
- Plotly
- Streamlit

## Запуск

```bash
pip install -r requirements.txt
python generate_data.py
streamlit run app.py
